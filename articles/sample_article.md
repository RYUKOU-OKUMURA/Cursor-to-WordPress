# サンプル記事：Cursor → WordPress自動投稿ツールの使い方

この記事は、Cursor → WordPress自動投稿ツールのサンプル記事です。

## はじめに

このツールを使うと、Cursorエディタで書いたMarkdownファイルを、コマンド一つでWordPressに投稿できます。

## 主な機能

- **Markdown対応**: 見慣れた記法でブログ記事を作成
- **自動変換**: MarkdownからHTMLへ自動変換
- **下書き/公開**: コマンドオプションで切り替え

## コードブロックの例

Pythonのコード例：

```python
def hello_world():
    print("Hello, World!")

if __name__ == "__main__":
    hello_world()
```

## リストの例

### 番号なしリスト

- 項目1
- 項目2
- 項目3

### 番号付きリスト

1. 最初のステップ
2. 次のステップ
3. 最後のステップ

## テーブルの例

| 機能 | 説明 |
|------|------|
| 下書き投稿 | `--draft` オプション（デフォルト） |
| 公開投稿 | `--publish` オプション |
