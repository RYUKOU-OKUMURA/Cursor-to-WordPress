# 他プロジェクトへの導入手順

ブログ記事を書いている別のディレクトリで、このWordPress投稿ツールを使う方法です。

## 方法1: シンボリックリンク（推奨）

スクリプト本体は1箇所で管理し、他プロジェクトからリンクで参照します。

### 手順

```bash
# ブログ記事用ディレクトリに移動
cd /path/to/your/blog-articles

# スクリプトへのシンボリックリンクを作成
ln -s /Users/ryukouokumura/Desktop/boss-workspace/Cursor-to-WordPress/post_to_wp.py post_to_wp.py

# .envファイルをコピー（認証情報は同じなら）
cp /Users/ryukouokumura/Desktop/boss-workspace/Cursor-to-WordPress/.env .env

# .vscodeディレクトリを作成してtasks.jsonをコピー
mkdir -p .vscode
cp /Users/ryukouokumura/Desktop/boss-workspace/Cursor-to-WordPress/.vscode/tasks.json .vscode/
```

### メリット
- スクリプトの更新が自動で反映される
- 管理が楽

### デメリット
- シンボリックリンクに慣れていないと混乱するかも

---

## 方法2: PATH に追加（グローバル利用）

スクリプトをどこからでも呼び出せるようにします。

### 手順

**1. スクリプトに実行権限を付与**
```bash
chmod +x /Users/ryukouokumura/Desktop/boss-workspace/Cursor-to-WordPress/post_to_wp.py
```

**2. シェル設定ファイルにエイリアスを追加**

`~/.zshrc` または `~/.bashrc` に追加：
```bash
# WordPress投稿ツール
alias wp-post="python /Users/ryukouokumura/Desktop/boss-workspace/Cursor-to-WordPress/post_to_wp.py"
```

**3. 設定を反映**
```bash
source ~/.zshrc
```

**4. 使い方**
```bash
# どこからでも実行可能
wp-post /path/to/article.md
wp-post /path/to/article.md --publish
```

### 注意
- `.env` ファイルはスクリプトのディレクトリか、実行ディレクトリに必要

---

## 方法3: tasks.json のみコピー（最小構成）

ブログ記事用ディレクトリに `.vscode/tasks.json` だけ置きます。

### 手順

**1. .vscode ディレクトリを作成**
```bash
cd /path/to/your/blog-articles
mkdir -p .vscode
```

**2. tasks.json を作成**

`.vscode/tasks.json`:
```json
{
  "version": "2.0.0",
  "tasks": [
    {
      "label": "WP: 下書き投稿",
      "type": "shell",
      "command": "python",
      "args": [
        "/Users/ryukouokumura/Desktop/boss-workspace/Cursor-to-WordPress/post_to_wp.py",
        "${file}"
      ],
      "problemMatcher": []
    },
    {
      "label": "WP: 公開投稿",
      "type": "shell",
      "command": "python",
      "args": [
        "/Users/ryukouokumura/Desktop/boss-workspace/Cursor-to-WordPress/post_to_wp.py",
        "${file}",
        "--publish"
      ],
      "problemMatcher": []
    }
  ]
}
```

### メリット
- 設定が最小限
- ブログディレクトリを汚さない

### 注意
- `.env` ファイルはスクリプトのディレクトリに必要（元の場所）

---

## 推奨構成

| 用途 | 推奨方法 |
|------|----------|
| 1つのブログだけ | 方法3（tasks.jsonのみ） |
| 複数ブログで使う | 方法2（PATH追加） |
| 開発も続ける | 方法1（シンボリックリンク） |

---

## トラブルシューティング

### `.env` が見つからない

スクリプトは以下の順序で `.env` を探します：
1. カレントディレクトリ
2. スクリプトのあるディレクトリ

見つからない場合は、ブログディレクトリに `.env` をコピーするか、スクリプトディレクトリに置いてください。

### 画像のパスが解決できない

画像は記事ファイルからの**相対パス**で指定してください：
```markdown
![画像](./images/photo.png)  # OK
![画像](/absolute/path/photo.png)  # OK
![画像](images/photo.png)  # OK
```
