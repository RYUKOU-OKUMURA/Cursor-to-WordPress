# 要件定義書（清書版）

**プロジェクト名**: Cursor → WordPress 自動投稿ツール
**バージョン**: 1.0
**作成日**: 2025-01-08
**対象ユーザー**: 非エンジニア（Cursor AIエージェントに指示を出して開発）

---

## 1. システム概要

### 1.1 目的
Cursorで執筆したブログ記事（Markdown形式）を、コマンド一つでWordPressに「下書き」または「公開」状態で自動投稿し、WordPress管理画面を開く手間を削減する。

### 1.2 スコープ

| フェーズ | 範囲 | 状態 |
|---------|------|------|
| **Phase 1（MVP）** | テキストのみの自動投稿 | 今回実装 |
| Phase 2 | JSON-LD対応、HTML直接入力対応 | 将来実装 |
| Phase 3 | 画像自動アップロード | 将来実装 |

## 2. 機能要件

### 2.1 Phase 1: 必須機能（今回実装）

#### F-01: Markdownファイル読み込み
- **説明**: 指定したMarkdownファイル（`.md`）をローカルから読み込む
- **入力**: ファイルパス（相対パスまたは絶対パス）
- **出力**: ファイル内容（文字列）
- **エラー処理**: ファイルが存在しない場合、明確なエラーメッセージを表示

#### F-02: タイトル自動抽出
- **説明**: Markdownファイルの先頭から記事タイトルを自動抽出
- **抽出ルール**:
  1. 最初の `# タイトル` 形式の行（H1見出し）
  2. H1がない場合、最初の `## タイトル` 形式の行（H2見出し）
  3. 見出しがない場合、ファイル名（拡張子除く）をタイトルとして使用
- **出力**: タイトル文字列（見出し記号 `#` は除去）

#### F-03: Markdown → HTML変換
- **説明**: Markdown本文をWordPressが表示できるHTML形式に変換
- **変換対象**:
  - 見出し（`##` → `<h2>`, `###` → `<h3>` など）
  - 段落（空行区切り → `<p>`）
  - 箇条書き（`- ` → `<ul><li>`）
  - 番号付きリスト（`1. ` → `<ol><li>`）
  - 強調（`**太字**` → `<strong>`, `*斜体*` → `<em>`）
  - リンク（`[text](url)` → `<a href="url">text</a>`）
  - コードブロック
- **注意**: タイトルとして抽出した見出しは本文から除去

#### F-04: WordPress REST API投稿
- **説明**: 変換したHTMLをWordPress REST APIで投稿
- **投稿データ**:
  - `title`: 抽出したタイトル
  - `content`: 変換したHTML
  - `status`: `draft`（下書き）または `publish`（公開）
- **認証**: Application Passwords（Basic認証）
- **成功時**: 投稿ID、編集画面URL、公開URLを表示
- **失敗時**: HTTPステータスコードとエラー内容を表示

#### F-05: 投稿モード選択
- **説明**: コマンドラインオプションで投稿状態を選択
- **オプション**:
  - `--draft`（デフォルト）: 下書きとして保存
  - `--publish`: 即時公開
- **デフォルト動作**: オプション省略時は下書き

#### F-06: 設定の外部管理
- **説明**: 機密情報をコードに直書きせず、`.env`ファイルで管理
- **管理項目**:
  - `WP_URL`: WordPressサイトのURL（例: `https://example.com`）
  - `WP_USER`: WordPressユーザー名
  - `WP_APP_PASSWORD`: アプリケーションパスワード
- **セキュリティ**: `.env`は`.gitignore`に追加し、Git管理外とする

---

### 2.2 Phase 2: 追加機能（将来実装）

#### F-07: Front Matter対応
- **説明**: YAML形式のメタデータからタイトル・カテゴリー・タグを読み取る
- **形式**:
  ```yaml
  ---
  title: 記事タイトル
  categories: カテゴリー1, カテゴリー2
  tags: タグ1, タグ2
  ---
  ```

#### F-08: JSON-LD埋め込み対応
- **説明**: SEO用のJSON-LDスクリプトを本文末尾に含めて投稿
- **入力**: HTMLファイル（JSON-LD含む）
- **処理**: `<head>`内のJSON-LDを`<body>`末尾に移動

#### F-09: HTMLファイル直接入力
- **説明**: Markdown変換済みのHTMLファイルを直接入力として受け付ける
- **判定**: 拡張子が`.html`の場合、変換をスキップ

---

### 2.3 Phase 3: 拡張機能（将来実装）

#### F-10: 画像自動アップロード
- **説明**: 記事内のローカル画像を自動検出しWordPressにアップロード
- **処理**:
  1. `![alt](path)` 形式の画像パスを正規表現で検出
  2. WordPress Media APIで画像をアップロード
  3. 本文内のパスをアップロード先URLに置換

#### F-11: アイキャッチ画像設定
- **説明**: 記事内の最初の画像をアイキャッチ画像として設定

## 3. 非機能要件

### 3.1 ユーザビリティ
| ID | 要件 | 基準 |
|----|------|------|
| NF-01 | シンプル実行 | ターミナルで1コマンドで実行可能 |
| NF-02 | 明確なフィードバック | 成功/失敗が一目でわかるメッセージ |
| NF-03 | ヘルプ表示 | `--help`オプションで使い方を表示 |

### 3.2 セキュリティ
| ID | 要件 | 基準 |
|----|------|------|
| NF-04 | 機密情報の分離 | パスワードをコードに直書きしない |
| NF-05 | Git除外 | `.env`をリポジトリに含めない |

### 3.3 エラーハンドリング
| ID | エラー種別 | 表示メッセージ例 |
|----|-----------|------------------|
| NF-06 | ファイル未発見 | `エラー: ファイル 'xxx.md' が見つかりません` |
| NF-07 | 認証失敗（401） | `エラー: 認証に失敗しました。ユーザー名とパスワードを確認してください` |
| NF-08 | 権限不足（403） | `エラー: 投稿権限がありません。ユーザーの権限を確認してください` |
| NF-09 | サーバーエラー（5xx） | `エラー: WordPressサーバーでエラーが発生しました` |
| NF-10 | ネットワークエラー | `エラー: WordPressに接続できません。URLとネットワークを確認してください` |
| NF-11 | 設定不足 | `エラー: .envファイルにWP_URLが設定されていません` |

### 3.4 拡張性
| ID | 要件 | 基準 |
|----|------|------|
| NF-12 | モジュール化 | 機能ごとに関数を分離し、後から修正しやすくする |
| NF-13 | 単一ファイル構成 | Phase 1は`post_to_wp.py`1ファイルで完結 |

### 3.5 コスト
| ID | 要件 | 基準 |
|----|------|------|
| NF-14 | 無料 | すべて無料のツール・ライブラリのみ使用 |

## 4. 前提条件

### 4.1 WordPress側の準備
- [ ] WordPress 5.6以上（REST API標準対応）
- [ ] Application Passwords機能が有効（WordPress 5.6以上で標準搭載）
- [ ] ユーザーが「投稿者」以上の権限を持っている
- [ ] REST APIが有効（`https://サイトURL/wp-json/` にアクセスして確認）

### 4.2 ローカル環境
- [ ] Python 3.8以上がインストールされている
- [ ] pipが使用可能
- [ ] インターネット接続が可能

## 5. 受け入れ基準（Phase 1）

### テストケース

| ID | テスト内容 | 期待結果 |
|----|-----------|----------|
| T-01 | 正常系：Markdownファイルを下書き投稿 | 下書きとして保存され、編集URLが表示される |
| T-02 | 正常系：Markdownファイルを公開投稿 | 公開され、公開URLが表示される |
| T-03 | 異常系：存在しないファイルを指定 | エラーメッセージが表示される |
| T-04 | 異常系：間違ったパスワードで実行 | 認証エラーが表示される |
| T-05 | 異常系：.envファイルがない | 設定エラーが表示される |

## 6. 用語集

| 用語 | 説明 |
|------|------|
| WordPress REST API | WordPressが提供するHTTP API。外部からプログラムで投稿・取得が可能 |
| Application Passwords | WordPress標準の認証機能。アプリ専用のパスワードを発行できる |
| Markdown | 軽量マークアップ言語。`#`で見出し、`-`で箇条書きなど |
| JSON-LD | 構造化データ形式。SEO（検索エンジン最適化）に使用 |
| MVP | Minimum Viable Product。最小限の機能で動作する製品 |
